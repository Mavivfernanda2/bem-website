# 🚀 BEM Website

Website resmi **Badan Eksekutif Mahasiswa (BEM) UNUSIDA** yang digunakan untuk mengelola informasi organisasi, berita, dan sistem administrasi.

---

## 📌 Fitur Utama

* 🏢 Manajemen organisasi (BEM & HIMA)
* 📰 Sistem berita organisasi
* 👨‍💻 Dashboard admin
* 📊 Relasi data antar organisasi
* 🔐 Sistem backend berbasis Laravel

---

## 🛠️ Teknologi yang Digunakan

* **Laravel** (PHP Framework)
* **MySQL** (Database)
* **Vite** (Frontend build tool)
* **Blade Template**

---

## ⚙️ Cara Menjalankan Project

```bash
git clone https://github.com/Mavivfernanda2/bem-website.git
cd bem-website
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
