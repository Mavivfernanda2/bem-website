# IPNU IPPNU Digital Platform

> Modern fullstack organization platform built with React + Hono.js + Prisma

## Tech Stack

- **Frontend**: React + Vite + TypeScript + Framer Motion
- **Backend**: Node.js + Hono.js + Prisma ORM + Zod
- **Database**: PostgreSQL (Neon)
- **Storage**: Supabase Storage
- **Deploy**: Vercel

## Getting Started

```bash
# Install all dependencies
npm run install:all

# Run development servers
npm run dev
```

## Project Structure

```
├── frontend/          # React SPA
├── backend/           # Hono.js API
├── shared/            # Shared types & utilities
└── docs/              # Documentation
```
